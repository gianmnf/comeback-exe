# COMEBACK.exe

A dark-futurist / Y2K-inspired developer portfolio starter built with Next.js 15, React and TypeScript.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing

Replace these placeholders in `app/page.tsx`:

- `hello@example.com` with your real contact email.
- GitHub and LinkedIn links with your profiles.
- Confirm the project descriptions, dates, metrics and technology stacks.
- Add a real CV PDF to `public/` and link it from the hero.
- Replace the temporary project artwork with approved screenshots or custom artwork.

## Current scope

- Responsive single-page homepage
- Dark futuristic visual system with pearl/chrome accents
- CSS-generated release artwork
- Project, profile, credits and contact sections
- Reduced-motion support
